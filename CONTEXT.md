# Decomp Atlas

A community catalogue of decompilation projects and practical contribution guidance.

## Language

**Listing**: An attributed record of an upstream decompilation repository, its target platform, and contribution links.

**Upstream**: The original project and maintainers whose code and contribution rules a listing references.

**Submission ticket**: A request to add a repository to Atlas, reviewed before a catalogue change is accepted.

**Progress board**: An upstream visualization of comparison measurements for code units and functions. It does not inherently assign work to contributors.

**Unit**: A group of compiled code, usually a translation unit, represented in a comparison report.

**Matching**: Reconstructed code producing the reference machine code under the project's comparison rules.

**Source coverage**: How much original code has been reconstructed as source, according to the upstream project's stated methodology.
